HAYGER 4.0 — HABIT SYSTEM + COACH

Major upgrade from HAYGER 3.0.

NEW
- Personal habit system: add up to 6 small daily habits.
- Per-day habit completion with 30-day completion rates.
- Weekly missions that rotate automatically between consistency, habits, focus and reflection.
- Coach screen with personalized, deterministic guidance based on streak, consistency, energy, habits and mission progress.
- Personal Signals: consistency, average logged energy, habit completion rate, best check-in day and mood distribution.
- New PLAN and COACH navigation sections.
- Existing HAYGER features remain available: check-ins, moods, Daily Focus, notes, calendar/history, stats, awards, goals, profile, PIN lock, reminders, themes, backup/restore, PWA update flow.

DATA
- All new data remains local on the device.
- Existing HAYGER 3 data is retained.
- Reset All HAYGER Data now also clears habits, habit history and weekly missions.

INSTALL
1. Serve this folder from HTTPS or localhost for full PWA/service-worker behavior.
2. Open index.html / the hosted app.
3. Existing HAYGER data is read from the same localStorage keys.
4. The service worker cache is versioned as HAYGER 4.0.
